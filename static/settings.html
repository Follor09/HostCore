Konto

Zugangsdaten für das Dashboard. Beim Speichern werden alle anderen Geräte abgemeldet.

Ansehen ohne Login

Für ein Wanddisplay: Jeder im Netzwerk sieht das Dashboard. Aktionen, Updates und diese Seite brauchen weiterhin ein Login.

Alle anderen Geräte abmelden

Beendet jede Sitzung außer dieser – z.B. wenn ein Gerät verloren ging.

Wetter

Ort für das Wetter-Widget. Koordinaten werden über Open-Meteo ermittelt.

Dienste

Welche Kacheln im Widget „Server-Dienste“ angezeigt werden. Änderungen werden sofort gespeichert.

Benachrichtigungen

Push-Nachrichten aufs Handy über ntfy: App installieren, ein Thema abonnieren und dessen URL hier eintragen. Auf ntfy.sh ist jedes Thema öffentlich – nimm einen langen, zufälligen Namen.

Benachrichtigungen senden

Warnungen erscheinen immer auch in der Glocke im Dashboard.

Warnen bei

0 °C / 0 % schaltet eine Schwelle ab. Eine Warnung kommt erst, wenn der Zustand mehrere Minuten anhält, und einmal, wenn er behoben ist.

Wake-on-LAN

Geräte, die im Dashboard per Klick geweckt werden können. Wake-on-LAN muss im BIOS / in der Netzwerkkarte des Geräts aktiviert sein.

Auto-Update

Der Pi prüft jede Minute GitHub und installiert neue Commits automatisch.

Verlauf

Messwerte für das Verlaufsdiagramm (CPU, Temperatur, RAM, Netzwerk, Lüfter).
