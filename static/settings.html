Konto

Dein Zugang zum Dashboard. Beim Ändern des Passworts werden deine anderen Geräte abgemeldet.

Ansehen ohne Login

Für ein Wanddisplay: Jeder im Netzwerk sieht das Dashboard. Aktionen, Updates und diese Seite brauchen weiterhin ein Login.

Alle anderen Geräte abmelden

Beendet deine Sitzungen auf allen anderen Geräten – z.B. wenn ein Gerät verloren ging.

Benutzer

Wer sich am Dashboard anmelden darf und in welcher Gruppe. Die Gruppe bestimmt die Rechte (siehe Berechtigungen). Deaktivierte Benutzer werden sofort abgemeldet.

Benutzer hinzufügen

Das Passwort teilst du der Person selbst mit – sie kann es danach unter „Konto“ ändern.

Berechtigungen

Was jede Gruppe darf. Ein Haken wird sofort gespeichert und gilt ohne neue Anmeldung. Administratoren dürfen immer alles.

Neue Gruppe

Remote-Pis

Weitere Raspberry Pis mit diesem Dashboard steuern. Auf dem anderen Pi läuft dazu der PiCore-Agent – dann lässt sich oben rechts zwischen den Pis wechseln, und alles (Live-Werte, Dienste, Container, Dateien, Terminal, Firewall, Updates …) zeigt den gewählten Pi. Rechte und Anmeldung bleiben die von diesem Dashboard.

Pi hinzufügen

So wird ein Pi zum Agent
  1. Auf dem anderen Pi das Repository klonen (wie beim ersten Pi) und im Ordner ./install.sh --agent ausführen.
  2. Am Ende stehen Adresse und Token im Terminal – beides hier eintragen. Später zeigt ./agent.sh token den Token wieder.
  3. Der Agent hat keine eigene Oberfläche und kein Login, aktualisiert sich aber wie dieses Dashboard automatisch von GitHub.
  4. Der Token wird im Klartext übertragen: Remote-Pis am besten nur im Heimnetz oder über das VPN (NetBird) ansprechen. Neuer Token: ./agent.sh rotate.

Sprache

Sprache der Oberfläche. Wird in diesem Browser gespeichert.

Darstellung

Hell, dunkel oder automatisch passend zur Einstellung deines Geräts, dazu eine Akzentfarbe. Wird in diesem Browser gespeichert.

Akzentfarbe

Wetter

Ort für das Wetter-Widget. Koordinaten werden über Open-Meteo ermittelt.

Dienste

Welche Kacheln im Widget „Server-Dienste“ angezeigt werden. Änderungen werden sofort gespeichert.

Wake-on-LAN

Geräte, die im Dashboard per Klick geweckt werden können. Wake-on-LAN muss im BIOS / in der Netzwerkkarte des Geräts aktiviert sein.

Web-Dienste

Eigene Dienste im Heimnetz oder VPN, deren Erreichbarkeit der Pi regelmäßig prüft (z.B. Home Assistant, NAS, Grafana). Jede Antwort unter HTTP 400 zählt als erreichbar – auch eine Login-Seite.

Ohne „Zertifikat prüfen“ werden auch selbst-signierte HTTPS-Zertifikate akzeptiert (üblich im Heimnetz).

Eigene Links

Links zu deinen Diensten (Home Assistant, Router, Grafana …). Sie erscheinen oben im Dashboard unter „Links“ und in der Suche (Strg+K) – auf allen Geräten.

Freigabe-Links

Aktive Download-Links für einzelne Dateien (erstellt in der Datei-Vorschau). Jeder mit dem Link kann die Datei ohne Anmeldung laden, bis der Link abläuft oder du ihn beendest.

Auto-Update

Der Pi prüft jede Minute GitHub und installiert neue Commits automatisch.

Verlauf

Messwerte für das Verlaufsdiagramm (CPU, Temperatur, RAM, Netzwerk, Lüfter).
