API-Dokumentation

Alle Schnittstellen des Dashboards – für eigene Skripte, Home-Automation oder zum Nachsehen, was eine Seite abfragt. Erzeugt aus dem Dashboard selbst, also immer aktuell. Jede Anfrage braucht eine Anmeldung und die angegebene Berechtigung; „wird weitergeleitet“ heißt: ist oben ein Remote-Server gewählt, antwortet dieser.

Aus einem Skript aufrufen
  1. Anmelden und das Sitzungs-Cookie speichern:
    curl -c picore.txt -H 'Content-Type: application/json' -d '{"username":"…","password":"…"}' http://<Server>:8000/api/auth/login
  2. Lesen: curl -b picore.txt http://<Server>:8000/api/status-summary
  3. Ändern (POST) braucht zusätzlich den Origin des Dashboards:
    curl -b picore.txt -H 'Origin: http://<Server>:8000' -H 'Content-Type: application/json' -d '{…}' http://<Server>:8000/api/…
  4. Für Skripte am besten einen eigenen Benutzer mit nur den nötigen Rechten anlegen (Einstellungen → Benutzer). Für Claude gibt es den MCP-Server.
